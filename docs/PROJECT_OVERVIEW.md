# Ivan Weiss Van Der Pol Portfolio - Project Overview

## 🎯 Project Summary

This is a professional portfolio website for Ivan Weiss Van Der Pol, built using Astro framework. The portfolio showcases professional experience, skills, projects, and educational background in computer science and data engineering.

## 🚀 Technology Stack

### Core Framework
- **Astro 5.12.3**: Static site generator optimized for content-focused websites
- **TypeScript**: Type-safe JavaScript for enhanced developer experience
- **Node.js**: JavaScript runtime environment

### Frontend Technologies
- **Vanilla JavaScript**: For interactive components and animations
- **CSS3**: Modern styling with custom properties and responsive design
- **HTML5**: Semantic markup for accessibility

### Development Tools
- **ESLint**: Code linting with TypeScript and Astro support
- **Prettier**: Code formatting with Astro plugin
- **NPM**: Package management

### Animation & UX
- **sal.js 0.8.5**: Scroll animation library for smooth reveal effects
- **Custom animations**: Performance-optimized CSS animations

## 📦 Build & Deployment

- **Static Output**: Generates static HTML for optimal performance
- **GitHub Pages**: Deployed at https://ivanweissvanderpol.github.io
- **Build Command**: `npm run build`
- **Preview**: `npm run preview`
- **Development**: `npm run dev`

## 🔧 Development Workflow

1. **Local Development**: `npm run dev` for hot-reload development server
2. **Code Quality**: ESLint and Prettier for consistent code style
3. **Type Checking**: TypeScript validation with `npm run typecheck`
4. **Validation**: Combined checks with `npm run validate`
5. **Clean Build**: `npm run clean` to reset build artifacts
